# Build brief
## Platform
Node 22 server, plain JavaScript front end that works on a phone and offline for already-loaded screens, MariaDB in live mode, in-memory demo store otherwise.

## Delivered
Request, approval (one or two steps), driver assignment (automatic or by acceptance), trip tracking by phone or vehicle tracker, reports and CSV, places management, parts requests, in-app messages, retention script.

## Not delivered
SMS and email messages, road routing against a real service, PHP port, real brand files. See Not Built and Known Issues.

## Cost
Cost to build and run is not yet modelled for this project; the cost model is a separate document.
