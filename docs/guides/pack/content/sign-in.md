# Sign-in
## Demo
The demo site shows a card for each made-up person. Tap a card to sign in. The demo password is shown by the app in demo mode only.

## Real accounts
Accounts are created from the people import (see the Administrator Guide). Each person gets a temporary password that they change at first use. After five wrong tries the account is locked for 15 minutes.

> CAUTION Never share a password or write it in a chat or document.
