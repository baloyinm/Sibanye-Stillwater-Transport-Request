# User test guide
## Test environment
Use the demo site only. It holds made-up people, places and trips and is reset whenever it restarts. Nothing you do is real and nothing is sent to anyone.

## How to test
1. Sign in as the person named in each scenario (tap their card).
2. Follow the steps in the End-to-end Scenarios document.
3. Write what you saw in the Acceptance Test Script and mark Pass or Fail.
4. Test on a phone and on a computer.
