# Concept
## What the Transport Hub is for
The Transport Hub lets people on the sites ask for a vehicle, lets a controller approve the trip and send a driver, and lets everyone see where the trip stands. It replaces phone calls and paper requests with one record per trip.

## How it works
1. A requester asks for a trip (people, or parts when switched on).
2. The controller approves or rejects it. With the two-step setting, a supervisor endorses it first.
3. The controller chooses a free driver, nearest first.
4. The driver starts the trip, shares the vehicle position and completes it.
5. Everyone sees the status and history. The controller reads reports.

## What is real and what is demo
All names, places and trips in this pack are made up. The app runs on demo data until the live database is set up and the people list is imported.
